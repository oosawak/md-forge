# map.md — 部屋の定義

`## 部屋 ID 表示名` の下に、コードブロックで部屋の形を描きます。
`#` は壁、`.` は床、`@` は始めの位置。そのほかの記号は、下の表で意味を決めます（表に無い記号は床になります）。

表の列：

- 種類：`扉`（通ると移動）・`調べる`（ぶつかる。調べるとイベント）・`置物`（ぶつかる。調べるとイベント、空でもよい）・`床`（踏むとイベント）・`敵`（敵が出る）・`番人位置`（追跡のとき番人が出る所）
- 対象：扉は `部屋ID:記号`（着く場所）、調べる・置物・床はイベント名、敵は enemies.md の敵の名前
- 条件：扉は開くための条件、敵は出てくる条件、ほかはイベントが動く条件（書き方は scenario.md と同じ）
- だめなとき：条件が合わないときに動くイベント
- 絵：表示する 1 文字（絵文字も可）。色：下地の色。光：周りを照らす広さ（マス）
