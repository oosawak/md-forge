# map.md — エデン生命科学研究所（横スクロール版・全 16 部屋）

横から見た部屋を、**2 行**で描きます。書き方の全体は scenario.md の `## 書き方` にもあります。

- 1 行目：**壁の列**（絵・額縁・張り紙・スイッチ・覗き穴・窓・扉・階段など、壁についている物）
- 2 行目：**床の列**（家具・暗幕・敵・`@` 始めの位置など、床に置く物）
- 1 文字が横 1 マス。`.` は何もない所。`|` と `#` は行き止まり（両端に置く）。2 行は同じ長さにそろえると読みやすい
- 同じ記号は 1 つの意味しか持てません（壁の列と床の列で別の記号を使う）
- 同じ列に壁の物と床の物を置くと、「調べる」は床の物、↑ は壁の物を調べます

コードブロックの外に、部屋の設定を書けます（省略可）：

- `- 壁の色：#2c2430` / `- 床の色：#221a16`
- `- 明るさ：0`（0＝真っ暗で灯の届く所だけ見える〜1＝全部見える）

表の列（空欄でよい列は省略してもかまいません）：

| 列 | 意味 |
| --- | --- |
| 記号 | コードブロックの中の 1 文字 |
| 種類 | `調べる`（前で調べるとイベント）・`置物`（調べるとイベント。対象が空なら飾り）・`扉`・`階段`（前で ↑ か「調べる」で移動）・`隠れる`（前で調べると隠れる。左右に動くと出る。対象にイベントを書くと、隠れたときに動く）・`障害`（条件が合うまで通れない。ぶつかると「だめなとき」）・`床`（その位置まで歩くとイベント）・`敵`・`番人位置`（追跡のとき番人が出る所） |
| 対象 | 扉・階段は `部屋ID:記号`（着く場所）。調べる・置物・床はイベント名。敵は enemies.md の敵の名前 |
| 条件 | 扉は開く条件、敵は出てくる条件、ほかはイベントが動く条件（書き方は scenario.md と同じ） |
| だめなとき | 条件が合わないときに動くイベント（鍵のかかった扉など） |
| 出る | この条件が合うまで、その物は無いのと同じ（見えない・調べられない・光らない）。隠し扉や、灯りを点けると現れる文字に |
| 見た目 | 描き方。下の一覧。`名前:状態` の形で、イベントの `[変化 記号 見た目]` で書き換えられる |
| 絵 | 見た目が無いときに出す 1 文字（絵文字も可） |
| 色 | 下地や扉の色 |
| 光 | 周りを照らす広さ（マス）。見た目に「消」が付いている間は光らない。「赤」が付くと部屋を赤く染める |
| 通ったら | 扉・階段を通って着いたときに動くイベント（「入室:部屋ID」より先に動く）。閉めた扉の背後から何か来る、など |

見た目の一覧：

- 壁：`絵`（肖像。`絵:目` 目が主人公を追う・`絵:泣く`・`絵:笑う`・`絵:無い` 人物が抜け出た）・`写真`（家族写真。`写真:目`・`写真:欠け` まん中が消えた・`写真:空き` 一人分の空白）・`額縁`（空の額）・`風景`（`風景:赤`）・`張り紙`（`張り紙:白`・`張り紙:血`）・`スイッチ`（`スイッチ:入`）・`覗き穴`（`覗き穴:目`）・`窓`（`窓:手` 手形・`窓:顔`・`窓:白`）・`時計`（`時計:逆` 針が逆に回る）・`鏡`（近づくと自分が映る。`鏡:影`）・`ランプ`（`ランプ:赤`・`ランプ:消`）
- 扉・階段：`扉`（`扉:鉄`・`扉:開`）・`階段:上`・`階段:下`。種類が `調べる` でも見た目を `扉` にすると扉の絵になる（玄関など、イベントで扱いたい扉）
- 床：`カウンター`・`机`・`長椅子`・`椅子`・`棚`・`カーテン`／`暗幕`・`ロッカー`（隠れると、中から扉のすき間ごしに外を見る画面になる。`ロッカー:開` 半開き）・`カメラ`・`台`・`花台`・`箱`

scientists-side で足した見た目（研究所用）：

- 壁：`モニター`（心拍の波形。`モニター:消`）・`金庫`・`黒板`・`窓口`（受付の小窓）・`パネル`（テンキーの操作盤。`パネル:開` で表示が緑）・`非常灯`（緑の誘導灯。光と組み合わせる）
- 扉：`扉:カード`（横にカードリーダー）・`扉:テンキー`（横にテンキー）。どちらも条件が合うとランプが緑になる。`扉:門`（格子の門）
- 床：`槽`（液体の円筒の槽。`槽:空`）・`檻`（`檻:壊れ`）・`ベッド`・`制御盤`・`下駄箱`・`消毒装置`（`消毒装置:動`）・`瓦礫`・`本棚`・`植木`・`流し`・`人:名前`（characters.md のその人をその場に描く）
- `机`・`台`・`ロッカー` に「絵」も書くと、上に小さく絵を置く（机の上の日誌など）

元の scientists/map.md からの変更：部屋 ID・扉の記号と行き先・条件・だめなとき・敵の出る条件・調べる対象のイベント名は同じです。位置は横 1 列に並べ直しました（扉の左右は部屋の端、奥の扉は壁の途中）。ロッカーは labA_ward・labB_hall・labC_room にあり、横スクロールでは敵をやり過ごすのに隠れる所が要るので、labA_ward のロッカーを 4 つに、labB_hall に「檻の陰」（隠れる）を 2 つ、holding にロッカーを 2 つ足しました。見回りの実験体が隠れ場所の前を通り過ぎるよう、隠れ場所は見回りの範囲（持ち場の左右 5 マス）の内側、端から 2 マス以上内に置いています。
