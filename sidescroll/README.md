# 止まり写真館 — md-forge Horror エンジン横スクロール版（試作）

`scientists/` のエンジンをコピーして、**横から見た部屋を左右に歩く**探索ホラーにしたものです。`horror/` と `scientists/` は変更していません。

確認用の短いサンプル（4 部屋・エンディング 1 つ）が入っています。シナリオは .md を書き換えれば差し替えられます。

## 遊び方

- 移動：←→ キー / AD / ドラッグ（スマホは左下のスティック）
- 調べる・会話を進める：スペース / Enter / Z / タップ。調べられる物の上に ▼ が出る
- 扉・階段：前で ↑（スティックを上へ）か「調べる」。同じ列に壁の物と床の物があるときは、「調べる」は床の物、↑ は壁の物
- 隠れる：暗幕の前で「調べる」。左右に動くと出る。見回りの敵は向いている方しか見ず、隠れていると気づかずに通り過ぎる
- 持ち物：I キー / 「持ち物」ボタン。灯（右上のろうそく）が体力

## scientists/ からの主な違い

| 項目 | 内容 |
| --- | --- |
| 部屋（map.md） | コードブロックが 2 行：1 行目が壁の列、2 行目が床の列。部屋ごとに `- 壁の色：` `- 床の色：` `- 明るさ：` |
| 表の列 | `出る`（条件が合うまで無いのと同じ）・`見た目`（絵・写真・張り紙・スイッチ・覗き穴・窓・時計・鏡・ランプ・扉・階段・家具など）・`通ったら`（扉を通って着いたときのイベント） |
| 種類 | `階段`・`隠れる`・`障害` が増えた |
| 命令 | `[変化 記号 見た目]` `[文字 文]` `[落書き 記号 文]` `[手 記号]` `[振り向く]` `[向き 左/右]` |
| 敵 | 左右だけに動く。見回りは向いている方だけを見る。番人（追跡）は「番人位置」→ 入ってきた扉（背後）→ 背中側から出る |
| 流用 | イベント DSL・灯・持ち物・フラグ・数値・追跡・自動セーブ・目的表示・タイトル・全体図・スマホ操作・でんきチップ |

書き方の詳細は `scenario.md` の `## 書き方` と、`map.md` の冒頭にあります。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | エンジン（scientists/ のコピー＋横スクロール化） |
| `scenario.md` | 設定・イベント・書き方 |
| `map.md` | 4 部屋（待合室・写真の廊下・暗室・撮影室） |
| `characters.md` / `items.md` / `enemies.md` | 人物・持ち物・敵と番人 |
| `fonts/` | でんきチップ（x8y12pxDenkiChip、SIL OFL 1.1） |
| `tools/embed.py` | .md を index.html に埋め込む（file:// で開くとき用） |

## ローカルで開く

```bash
python3 -m http.server 8000
```

`http://localhost:8000/sidescroll/` を開きます。.md を書き換えたら `python3 sidescroll/tools/embed.py` で index.html にも埋め込めます（file:// で開くとき用）。
