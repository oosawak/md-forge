# Markdown鍛造（仮）

鉱石を砥石で削って武器を作り、Markdown を合成して強くし、自動バトルで先へ進む試作ゲームです。

遊ぶ: https://oosawak.github.io/md-forge/

## 遊び方

1. **鍛造**：型は 長剣・大剣・短剣・斧・槍 から選べます。最初に「材料」「持ち手」「鞘」を選びます。材料は硬さ・性能・出やすい属性が違います。持ち手（鍔と柄）は鉱石に最初から付いていて削れず、削るのは刀身だけです。持ち手と鞘は、それぞれ剣に効果を 1 つ付けます。相性の良い組み合わせだと、ときどき「共鳴」して剣に銘が刻まれ、効果が上乗せされます。
   鉱石の中の金色の点々は「輝石の粒」で、完成した刃に残した数だけ良いレアリティが出やすくなり攻撃も上がります（削ると少し金が入ります）。どこを刃にするか、2 振りならどちらに粒を寄せるかで差が出ます。1 振りのときは「剣の位置」（◀剣 剣▶）で、持ち手とガイドを鉱石の上で左右に動かして、粒の多い所から剣を作れます。
   次に砥石を選び、鉱石をドラッグして回る砥石に押し当てて削ります。点線のガイドに近い形ほど、良いレアリティが出やすくなります。「完成」を押すとハンマーで叩く工程になります。刀身に光る点が出て、その色で付く能力（攻撃・会心・速度・防御・スキル）が決まります。輪が点に重なった瞬間にタップ（スペースキー）すると「会心の一打」です。叩き終わると性能が決まります（自動鍛造ではハンマーを使いません）。
   - 「2振り（1枚から）」を選ぶと、1 枚の大きな鉱石に持ち手が 2 つ付き、同じ型の剣を 2 振り打てます（鉱石を 1 つ多く使います）。ハンマーも 2 振りぶん、左右交互に叩きます。2 本は「対の剣」で、片方を装備してもう片方が武器庫にあると二刀流になり、左手の剣がときどき追撃します。
   - 平砥石と尖り砥石は「角度」で向きを変えられます（↺ ↻ ボタン・スライダー、パソコンでは Q / E キーで 15° ずつ）。
   - 「持ち替え」で鉱石を左右・上下に反転できます。矢印キーでも鉱石を動かせます。
   - 「マウス操作」にチェックを入れると、ボタンを押さなくても鉱石がマウスに付いてきて、ホイールで砥石の角度を変えられます（初期はオフ）。
2. **合成**：武器に Markdown（.md ファイルのドラッグ＆ドロップか貼り付け）を合成すると強くなります。文字数・見出し・コードブロック・表・属性の単語で上がる値が変わります。
3. **バトル**：斜め上から見下ろす 1 本道のステージです。主人公が鍛えた武器を右手に持ち、上から来る敵と自動で戦います。ウェーブを突破するたびに道を上へ進み、5 ウェーブごとに大きな門の先から巨大なボスが出ます。標準の視点は「縦」（真後ろ上から。道が画面の下から上へまっすぐ続く）で、主人公を動かせます（矢印キー・WASD、またはドラッグ）。敵はいろいろな向きから現れます。「斜め」（右後ろ上から）に切り替えると、動かさずに見ているだけの自動バトルになります。ボスは前への長い攻撃と円状の攻撃を使い、地面の赤い範囲から出ればよけられます。敵は `enemies.md` の表で増やせて、動き（近づく・ふらふら・回り込む・突進・撃つ）も表で選べます。対の剣は、武器庫の「二刀流で装備」で二刀流になります。最初はサンプルの VRM（`models/` にある VRM1_Constraint_Twist_Sample、(c) 2022 pixiv Inc.、VRM Public License 1.0）が主人公です。自分の VRM ファイルを読み込むと入れ替わります。

はじめは「見習いの長剣」を 1 本持っていて、すぐバトルできます（最後の 1 本は売れません）。

記録はブラウザの localStorage に保存されます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム本体。three.js と three-vrm は CDN（jsDelivr）から読み込む |
| `balance.md` | 鍛造の抽選テーブル（レアリティ・性能・武器の型・砥石・属性・スキルなど） |
| `fusion.md` | Markdown 合成の換算ルール |
| `enemies.md` | バトルの敵・動き・ボス・ボスの技・弾の定義。行を足すと敵が増える |
| `models/` | 最初に表示するサンプルの VRM（ライセンスは `models/README.md`） |

`balance.md`・`fusion.md`・`enemies.md` は「`## 見出し` の下の最初の表」を定義として読みます。表を書き換えると、確率や換算が変わります。
読み込めない環境では、`index.html` に内蔵した同じ内容の初期値を使います。

`?2d` を付けて開くと、バトルを 2D 表示（横から見た簡易表示）で遊べます。
