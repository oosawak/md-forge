# 灯の館（仮）— Markdown で動く探索ホラー

閉じた建物を探索して、謎を解き、番人から逃げて外へ出る 2D 見下ろしの探索ホラーの試作です。
md-forge と同じく、`## 見出し` の下の表やテキストを定義として読みます。**.md を読み込むと、シナリオ・マップ・キャラ・敵がその場で変わります。**

今入っているのは、仕組みを確かめるための短いサンプル（3 部屋・追跡 1 回・エンディング 2 つ）です。

## 遊び方

- 移動：矢印キー / WASD / 画面をドラッグ
- 調べる・会話を進める：スペース / Enter / Z / タップ（スマホは右下の「調べる」）
- 持ち物：I キー / 「持ち物」ボタン
- 灯（ろうそく）が体力です。敵に触れたり番人の技に当たると 1 つ消え、0 でゲームオーバー（部屋の入口からやり直せます）。灯が多いほど周りが明るく見えます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム本体（ライブラリなし。canvas の 2D 描画） |
| `scenario.md` | `## 設定`（タイトル・開始部屋・灯の数）と `## イベント ID`（会話・分岐・命令）。書き方は `## 書き方` |
| `map.md` | `## 部屋 ID 表示名`。コードブロックで部屋の形、表で記号の意味（扉・調べる・敵など） |
| `characters.md` | `## キャラ`。主人公・同行者・番人の名前と色 |
| `items.md` | `## アイテム`。使える物（灯+1）と大事な物 |
| `enemies.md` | `## 敵` `## 動き` `## 番人` `## 技`。md-forge の敵の動きとボスの赤い範囲攻撃を流用 |
| `samples/swap-characters.md` | 読み込むと登場人物と玄関ホールが変わる例 |
| `tools/embed.py` | .md を index.html に埋め込む（file:// で開いたときの初期値用） |

## Markdown の差し替え

- 「Markdown」ボタンからファイルを選ぶ・貼り付ける、または画面に .md をドロップします。
- 同じ見出しの定義だけが置き換わります。`## 部屋 ID` と `## イベント ID` は ID で判定するので、表示名を変えても置き換わります。
- 新しい見出し（新しい部屋やイベント）は追加されます。
- シナリオで `{主人公}` `{同行者}` `{番人}` と書いておくと、キャラを差し替えたときにセリフの名前も変わります。
- 「最初の定義に戻す」で元に戻せます。

## ローカルで開く

.md を直接読むので、サーバー経由で開いてください（GitHub Pages ならそのまま動きます）。

```bash
python3 -m http.server 8000
```

`http://localhost:8000/horror/` を開きます。index.html を直接開いた場合は、埋め込んだ初期値で動きます（.md を書き換えたら `python3 horror/tools/embed.py` を実行）。
