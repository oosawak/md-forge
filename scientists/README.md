# SCIENTISTS — md-forge Horror エンジン版

エデン生命科学研究所に潜入する探索ホラー。`horror/`（灯の館）のエンジンをコピーし、セーブ・カウンタ・持ち物の上限・実験体の見回り・暗号入力・アイテム効果・隠し扉を足したものです。`horror/` 本体は変更していません。

現在は **第1段**（潜入〜研究棟A クリア）まで遊べます。

## 遊び方

- 移動：矢印キー / WASD / ドラッグ（スマホは左下のスティック）
- 調べる・会話を進める：スペース / Enter / Z / タップ
- 持ち物：I キー / 「持ち物」ボタン（追跡中も開ける。開いている間はゲームが止まる）
- 灯が体力。実験体に触れると 1 つ消え、0 でゲームオーバー（部屋の入口からやり直し。セーブは上書きしない）
- 実験体は倒せない。見つかると頭上に「!」、見失うと「?」。壁の陰に入る、空き瓶・発煙筒で気をそらす（3 秒止まる）

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | エンジン（horror/ のコピー＋拡張） |
| `scenario.md` | 設定・イベント。増えた命令は `## 書き方` |
| `map.md` | 部屋（エントランス・中央棟・職員室・旧資料室・研究棟A の 3 部屋） |
| `characters.md` / `items.md` / `enemies.md` | 人物・持ち物・実験体と番人 |
| `fonts/` | でんきチップ（x8y12pxDenkiChip、SIL OFL 1.1） |
| `tools/embed.py` | .md を index.html に埋め込む（file:// で開くとき用） |

## ローカルで開く

```bash
python3 -m http.server 8000
```

`http://localhost:8000/scientists/` を開きます。
