# scenario.md — SCIENTISTS 設定とイベント

md-forge Horror エンジン（scientists/ 版）用のシナリオです。潜入からエンディング（5 種）まで。

## 設定

| 項目 | 値 |
| --- | --- |
| タイトル | SCIENTISTS |
| 説明 | エデン生命科学研究所に潜入し、研究を止めて脱出する。エンディングは 5 種類。 |
| 開始部屋 | entrance |
| 開始イベント | opening |
| 最初の灯 | 3 |
| 灯の最大 | 5 |
| 持ち物の上限 | 4 |
| キャッチ | 生命の価値を決めるのは、誰なのか。 |
| 入室の猶予 | 2 |
| 最初の目的 | 研究所の証拠（研究資料）を集める |

## 書き方（scientists/ 版で増えた命令）

> - `[数値 名前 +1]` `[数値 名前 -1]` `[数値 名前 =0]`：カウンタ。条件は `数値:名前>=3`。セリフの中で `{数値:名前}` と書くと値が入る。
> - `[解放 名前]`：エリアを解放する。条件は `解放:名前`。
> - `[入力 答え → イベント]`：文字を入力させる。答えは `|` で区切って複数書ける。ひらがな・カタカナ・全角半角・大文字小文字の違いは区別しない。外れたら次の行へ進む。
> - `[取得 物]`：消耗品（items.md の「使う」がある物）は「持ち物の上限」まで。いっぱいのときは `## イベント 満杯` へ移る。
> - `[目的 文]`：画面上部の「目的：」を書き換える（`{数値:名前}` も使える）。最初の目的は設定「最初の目的」。
> - `[暗く]` `[明るく]`：画面を黒くしたまま文を出す／元に戻す（導入や場面転換用）。
> - 設定「キャッチ」はタイトルの下の一文、「入室の猶予」は部屋に入ってから実験体に見つからない秒数。
> - `[追跡 名前 秒数 → イベント]`：灯が尽きたらゲームオーバーではなく、そのイベントへ移る。
> - 条件 `部屋:ID`：今いる部屋。items.md の使う欄 `イベント:名前` で、使ったときにイベントを動かせる。
> - カウンタ：資料（回収した研究資料）・真相（ノワとリヒトの真相に関わる資料）・救った・安楽死・見送った
