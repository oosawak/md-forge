# enemies.md — 止まり写真館 敵・動き・番人・技

触れられると灯が 1 つ消え、0 でゲームオーバーです。主人公は戦えません。逃げる・隠れる・気をそらすで切り抜けます。

横スクロール版では、敵は左右にだけ動きます。

- 見回りの敵は、**向いている方**しか見ていません（画面ではうっすら赤い帯）。隠れている主人公には気づかず、すり抜けていきます。
- 隠れていると、見回り以外の敵も見失って止まります。番人（追跡）には隠れても見つかります。
- 横スクロール版で使える動き：近づく・ふらふら・突進・撃つ・見張り・うしろ・止まる・見回り（「見回り」で始まる名前も可）。それ以外は「近づく」になります。

## 敵

- 形：人形・影・目玉・獣・菌・鏡、または `人:名前`（characters.md のその人の姿で描く）
- 話す：近くで調べると動くイベント
- 害：`いいえ` と書くと、触れても灯が減らない（会話の相手など）

| 焼き付き | 影 | #000000 | 1.0 | 1.3 | 見回り影 | | | 現像に失敗した写真から抜け出した影。前しか見えない |

## 動き

| 動き | 値1 | 値2 | 説明 |

| 近づく | 0 | 0 | まっすぐ近づく |

| 突進 | 0.8 | 4 | 構えてから突っ込む（値1：構える秒、値2：速さの倍率） |

| うしろ | 0 | 0 | こちらが背中を向けている間だけ近づく |
| 止まる | 0 | 0 | その場から動かない |
| 見回り | 4 | 1.6 | 持ち場の左右 5 マスを歩き、立ち止まって振り返る。向いている方の値1 マス以内に入ると「!」で追う（速さの値2 倍）。隠れる・離れると「?」で探し、3 秒で持ち場へ戻る |
| 見回り影 | 4 | 1.7 | 見回りと同じ。少し速く追う |
