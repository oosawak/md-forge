# Markdown鍛造（仮）

鉱石を砥石で削って武器を作り、Markdown を合成して強くし、自動バトルで先へ進む試作ゲームです。

遊ぶ: https://oosawak.github.io/md-forge/

## 遊び方

1. **鍛造**：最初に「材料」「持ち手」「鞘」を選びます。材料は硬さ・性能・出やすい属性が違います。持ち手（鍔と柄）は鉱石に最初から付いていて削れず、削るのは刀身だけです。持ち手と鞘は、それぞれ剣に効果を 1 つ付けます。相性の良い組み合わせだと、ときどき「共鳴」して剣に銘が刻まれ、効果が上乗せされます。
   次に砥石を選び、鉱石をドラッグして回る砥石に押し当てて削ります。点線のガイドに近い形ほど、良いレアリティが出やすくなります。「完成」を押すとハンマーで叩く工程になります。刀身に光る点が出て、その色で付く能力（攻撃・会心・速度・防御・スキル）が決まります。輪が点に重なった瞬間にタップ（スペースキー）すると「会心の一打」です。叩き終わると性能が決まります（自動鍛造ではハンマーを使いません）。
   - 「2振り（1枚から）」を選ぶと、1 枚の大きな鉱石に持ち手が 2 つ付き、同じ型の剣を 2 振り打てます（鉱石を 1 つ多く使います）。ハンマーも 2 振りぶん、左右交互に叩きます。
   - 平砥石と尖り砥石は「角度」で向きを変えられます（↺ ↻ ボタン・スライダー、パソコンでは Q / E キーで 15° ずつ）。
   - 「持ち替え」で鉱石を左右・上下に反転できます。矢印キーでも鉱石を動かせます。
   - 「マウス操作」にチェックを入れると、ボタンを押さなくても鉱石がマウスに付いてきて、ホイールで砥石の角度を変えられます（初期はオフ）。
2. **合成**：武器に Markdown（.md ファイルのドラッグ＆ドロップか貼り付け）を合成すると強くなります。文字数・見出し・コードブロック・表・属性の単語で上がる値が変わります。
3. **バトル**：主人公が鍛えた剣を右手に持ち、自動で敵と戦います。5 ウェーブごとにボスが出ます。VRM ファイルを読み込むと、主人公をそのモデルにできます。

記録はブラウザの localStorage に保存されます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム本体。three.js と three-vrm は CDN（jsDelivr）から読み込む |
| `balance.md` | 鍛造の抽選テーブル（レアリティ・性能・武器の型・砥石・属性・スキルなど） |
| `fusion.md` | Markdown 合成の換算ルール |

`balance.md` と `fusion.md` は「`## 見出し` の下の最初の表」を定義として読みます。表を書き換えると、確率や換算が変わります。
読み込めない環境では、`index.html` に内蔵した同じ内容の初期値を使います。

`?2d` を付けて開くと、バトルを 2D 表示で遊べます。
