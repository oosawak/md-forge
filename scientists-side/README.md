# SCIENTISTS — 横スクロール版（scientists-side）

`scientists/` のシナリオ（scientists-stage2 の 766e6a8 時点）を、横スクロール版エンジン（`sidescroll/`、ロッカー入り）で遊べるようにしたものです。`scientists/`・`sidescroll/`・`horror/` は変更していません。

エデン生命科学研究所に潜入する探索ホラー。16 部屋・エンディング 5 種類（SECRET / GOOD / TRUE / NORMAL / BAD）。シナリオの筋・フラグ・エンディング条件は scientists/ と同じです。

## 遊び方

- 移動：←→ キー / AD / ドラッグ（スマホは左下のスティック）
- 調べる・会話を進める：スペース / Enter / Z / タップ。調べられる物の上に ▼ が出る
- 扉・階段：前で ↑（スティックを上へ）か「調べる」。同じ列に壁の物と床の物があるときは、「調べる」は床の物、↑ は壁の物
- 隠れる：ロッカー・檻の陰の前で「調べる」。左右に動くと出る。こちらを向いて追ってきている実験体の目の前で隠れると、見つかって灯が 1 つ消える
- 持ち物：I キー / 「持ち物」ボタン。空き瓶・発煙筒で気をそらしている 3 秒は、実験体や番人に触れても平気（すり抜けられる）
- 灯（右上のろうそく）が体力。0 でゲームオーバー（部屋の入口からやり直し）

## 実験体と番人（横スクロールでの動き）

- 見回り（ロスト・キメラ・ハウンド）：持ち場の左右 5 マスを端から端へ歩き、端で立ち止まって振り返る。向いている方しか見ていない（うっすら赤い帯）。隠れると気づかずに通り過ぎる。触れたあとは 1.2 秒よろける
- ドール（うしろ）：こちらが向いている間は動かない。正面を向いたまま近づいて話しかける
- パラサイト（広がる）：左右に分体を増やして通路をふさぐ。消毒装置で消える
- ミラー（先回り）：5 マス以内に入ると動きを学習して回り込む。急に向きを変えると外れる。離れるか隠れると持ち場へ戻る
- リヒト（止まる）：研究室で待っている
- 番人（追跡）：隠れても見つかる。扉から逃げれば振り切れる。技を構えている間（赤い範囲）は体に触れても平気なので、横をすり抜けられる。`前` の技は向いている方だけ。脱出口では扉が使えないので、25 秒逃げ切る（灯が尽きると BAD END）

## scientists/ から変えた所

| 項目 | 内容 |
| --- | --- |
| map.md | 16 部屋を、壁の列＋床の列の 2 行に描き直した。部屋 ID・扉の記号と行き先・条件・だめなとき・敵の出る条件・調べる対象のイベント名は同じ。中央棟の地下と収容エリアの出入口は種類を「階段」にした |
| 隠れる所 | 1 次元では敵をやり過ごすのに隠れる所が要るので、labA_ward のロッカーを 4 つに、labB_hall に「檻の陰」を 2 つ、holding にロッカーを 2 つ足した |
| 見た目 | 研究所用の見た目（モニター・培養槽・檻・ベッド・金庫・制御盤・黒板・下駄箱・消毒装置・本棚・非常灯・カードリーダー／テンキーつきの扉・テンキーの操作盤など）を足した。一覧は map.md の冒頭 |
| enemies.md | 番人の技の長さを横スクロール向けに短くした。キメラ・ハウンドの察知を短くし、ハウンドの追う速さを下げた（壁で視線が切れないため） |
| scenario.md | 操作説明・【ヒント】・目的の文の方角（北・南・西・東・壁の陰）を、左・右・奥の扉などに直した。見た目を変える `[変化]` を 4 か所に足した（前室のパネル・トワの槽・消毒装置・レンの椅子）。筋・フラグ・エンディング条件は変えていない |
| エンジン | sidescroll/ のエンジンに、ミラー・パラサイトの 1 次元版、隠れるときの「見られていた」、隠れている間に実験体が持ち場へ戻る、番人の技の構え中はすり抜けられる、弾は 6 マスまで、などを足した |

## ローカルで開く

```bash
python3 -m http.server 8000
```

`http://localhost:8000/scientists-side/` を開きます。セーブは scientists/ とは別に保存されます。
